## Problemas de ejecucion de proyecto

## ERROR AUTH issues
En app.ts -> adapterProvider

If you experience ERRO AUTH issues, check the latest WhatsApp version at:
  ** https://wppconnect.io/whatsapp-versions/

Example: version "2.3000.1035824857-alpha" -> [2, 3000, 1044231902]

Hoy 31 de julio de 2026 usamos 1044231902

# Flujo para usar el proyecto

bash
```
npm run dev
```
Aparecera en terminal

⚡⚡ ACTION REQUIRED ⚡⚡
You must scan the QR Code
Remember that the QR code updates every minute
Need help: https://link.codigoencasa.com/DISCORD
Official documentation: https://www.builderbot.app

En los archivos del proyectos abre el archivo bot.qr.png que se genere - cambia cada minuto

En tu WhatsApp -> dispositivos vinculados -> escanea dicho qr

en caso de error tira el proyecto y vuelve a levantarlo.
